# SAGE-Robot-Phase1

SAGE: The Robot with a Mission(Situational Awareness & Geolocation Entity)Welcome to the SAGE project! This repository marks the completion of Phase 1, where we’ve successfully built the "nervous system" for our autonomous defense robot. The goal was to give a machine the ability to see its surroundings, recognize people, and talk to the cloud—all at the same time.🕹️ See it in ActionI've built the entire hardware prototype in Wokwi so you can test it without needing a soldering iron.👉 Launch the Live Wokwi Simulation🧠 How the "Brain" WorksInstead of overloading one chip, I used a Dual-Board Architecture to keep the robot fast and responsive:The Muscle (Arduino Uno): Handles the "gritty" work. It pings the sensors every few milliseconds to ensure we aren't about to hit a wall or a person.The Voice (ESP32): Acts as our bridge to the world. It takes the data from the Arduino and gets it ready to upload to the AWS Cloud Dashboard.The "Senses" (Agents)The code is organized into specialized "Agents" to keep things modular:Navigator Agent: Uses those two ultrasonic "eyes" (front and back) to map out distances. If something gets too close, the Navigator knows it first.EMBER/Sentinel Agent: This is the "empathy" side of the robot. Using a PIR heat sensor, it detects when a human enters the room, triggering the robot's social interaction protocols.The IoT Link: This is the invisible wire. It packages all that sensor data into a neat message and sends it from the Arduino to the ESP32 via a Serial link.🛠️ The Tech StackMicrocontrollers: Arduino Uno + ESP32 DevKit V1.Sensors: 2x HC-SR04 (Ultrasonic) + 1x PIR (Motion).Communication: UART Serial Link (Arduino Pin 1 (TX) $\rightarrow$ ESP32 Pin 16 (RX2)).🚦 Quick Start GuideIf you want to play around with the simulation:Open the Wokwi link above.Hit the Green Play button.Interact: Click the sensors to change distances or trigger motion.Check the Console: You’ll see the "SAGE Status" updates rolling in—this is exactly what the robot would be "thinking" in real-time.Next Up for Phase 2: Adding the motor drivers to get this robot moving! 🚀
